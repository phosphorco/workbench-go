# Independent TDD review obligations

Review only a changed, declared lane; send concrete findings directly to its
implementer and root. All future reviewer BB threads use Codex Luna/xhigh/fast.
No overlapping edits, broad test reruns without a reason, or review churn when
hashes are unchanged. An early red test uses frozen binary d709734 at
/tmp/workbench-context-pre-pkl; final green must use current production code.

| Invariant | Executable counterexample |
| --- | --- |
| Single authority | JSON-only project appears enabled; both formats combine; old explicit home JSON is silently interpreted or switched. |
| No-source silence | Missing Pkl still resolves/starts private toolchain, creates cache, keeps daemon warm, or scans legacy config. |
| Nearest ownership | Empty/disabled/directory-only boundary revives parent contributors; child outside coverage loses blocking-origin explanation. |
| Exact freshness | Source changes and returns before a later hash; import symlink retargets to equal bytes; nearer file appears after negative lookup. |
| Bounded lifetime | Version, handshake, pipe read/write or cleanup outlives hook; cancellation kills parent but leaves evaluator or helper process. |
| Shared capacity | Two hooks and trace each spend same space; old trace cap keeps admitting after home cap shrinks; abandoned temp reservation remains uncharged. |
| Bootstrap | Home evaluation publishes cache under guessed cap before it has established actual home policy. |
| Ownership | Caller mutation alters retained dependency/settings strings; independent cache truth controls activation; different roots share scope identity. |
| Named contributors | A declaration named project-guidance produces ai-context identities in history, or two named builtins share receipts/source slots. |
| Capability dispatch | A profile-only contributor receives context.contribute, or a provider is called for a capability it declined during initialization. |
| Typed projection | Pkl preferences/exclusion scope/home limits or nested provider JSON are dropped or changed during canonical decoding. |
| TDD integrity | Red is compiler failure/missing test rather than observed behavior; fixture bypasses production loader or tests a duplicate resolver. |
| Usability | init overwrites authored expressions, treats creation as activation, silently displaces inherited providers, or docs still activate with JSON. |

Latency targets belong to stated workloads and complete start-to-joined-cleanup
measurement. Do not equate native-hook stdout with actual next-request model
admission. Do not equate synthetic quota tests with concurrent production trace
rotation plus snapshot publication. Probe findings can buy a narrower engineering
step, but cannot accept unrelated final integration obligations.
